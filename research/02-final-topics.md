# going-ai-native: Final Module List (for review)

**Thesis:** *autonomy should scale with verifiability.* Each module teaches one thing: how to make AI work checkable, and then how to use that check to steer, loop, or hill-climb.

Notation: **[new]** marks a module or section added after research. **[↑]** marks an existing one that was substantially expanded. Source keys refer to entries in `anthropic.md` (A), `openai-karpathy.md` (OK), `practitioners.md` (P), and `curricula.md` (C).

## Suggested learning path
- **Core track** (do these first, ~60% of the value): 00 → 01 → 04 → 07 → 10 → 11 → 12 → 13 → 14
- **Builder track:** 02 → 03 → 05 → 06 → 08 → 09
- **Production track:** 15 → 16 → 17 → 99

## Per-module format (Phase C)
- `README.md`: why it matters, the distributed-systems anchor, and learning goals
- `NN-<concept>.md`: one file per concept, following idea → why → how → worked example → pitfalls
- `examples.md`: realistic "Monday morning" scenarios
- `exercises.md`: each exercise has "done when" criteria
- `references.md`: sources, with what to take from each
- `code/`: runnable Python 3.11+ using the `anthropic` SDK and pytest. A shared `FakeClient` lets every test run offline.

For scale, that is 19 module folders. Estimated output is roughly 80–110 MD files plus code.
