# On-call escalation policy

## Paging
A page must be acknowledged within 5 minutes. If not, it escalates to the secondary, then to the team's engineering manager after 15 minutes.

## Incident commander
Any SEV1 needs an incident commander who is not debugging. The commander posts updates every 30 minutes.
