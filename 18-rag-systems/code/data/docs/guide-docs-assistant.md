# Using the docs assistant

## What it covers
The assistant answers from runbooks, ADRs, postmortems and guides. It cites every claim with a document and section, and says "not covered" when the docs do not answer.

## Freshness
Edits appear in answers within 5 minutes of merge. ACL changes follow the same SLO.
