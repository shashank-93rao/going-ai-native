## Primary: tool documentation

| Source | What to take from it |
|---|---|
| [Claude Code docs, "Best practices"](https://code.claude.com/docs/en/best-practices) (read 2026-10-19; originally the 2025-04-18 engineering blog post) | The core of this module. "If you could describe the diff in one sentence, skip the plan". The interview-to-SPEC.md prompt. `/clear` after two failed corrections. Writer/Reviewer. The `claude -p` fan-out loop and `/batch`. | [Claude Code docs, "Worktrees"](https://code.claude.com/docs/en/worktrees) (read 2026-10-19) | `--worktree`/`-w`, `.claude/worktrees/<name>`, `worktree-<name>` branches, `worktree.baseRef`, `.worktreeinclude`, cleanup rules (and that `-p` runs don't clean up), isolation checks and their limits, `isolation: worktree` for subagents. |
| [Claude Code docs, "Agent view"](https://code.claude.com/docs/en/agent-view) (research preview, read 2026-10-19) | `claude --bg`, `claude agents`, `attach`/`logs`/`stop`, per-session worktree isolation for background sessions. |
| [Claude Code docs, "Use Claude Code in the cloud"](https://code.claude.com/docs/en/claude-code-on-the-web) (read 2026-10-19) | `claude --cloud "<task>"` (clones the remote, so push first), `--teleport`, parallel cloud sessions, "plan locally, execute in the cloud". |
| [Claude Code docs, "Common workflows"](https://code.claude.com/docs/en/common-workflows) and ["Subagents"](https://code.claude.com/docs/en/sub-agents) | Plan mode entry points. | [Spotify Engineering, "Honk" series](https://engineering.atspotify.com/2025/11/spotifys-background-coding-agent-part-1) ([part 3](https://engineering.atspotify.com/2025/12/feedback-loops-background-coding-agents-part-3)) | Fan-out at fleet scale.
