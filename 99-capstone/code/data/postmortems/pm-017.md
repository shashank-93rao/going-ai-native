# Postmortem: checkout degradation (INC-2167)

**Author:** on-call, payments team

## Summary

A security group change removed the rule allowing traffic from checkout to ledger on port 5432. Customers saw elevated errors on checkout, inventory.

## Timeline (UTC)

- 14:24 Impact begins: error ratio on checkout starts rising.
- 14:54 First alert fired: error ratio above SLO on checkout.
- 14:57 Incident declared SEV2; incident commander assigned.
- 15:06 Upgraded to SEV1 after impact spread to inventory.
- 15:17 Mitigation applied.
- 15:41 Error rates back to baseline; incident resolved.

Customer-visible impact lasted from 14:24 until resolution at 15:41.

## Root cause

A security group change removed the rule allowing traffic from checkout to ledger on port 5432. Connections hung until TCP timeout rather than failing fast.

## Impact

Customers saw elevated errors on checkout, inventory. Affected services: checkout, inventory.

- [ ] Manage security groups through reviewed IaC only
- [ ] Add a synthetic probe for this path
