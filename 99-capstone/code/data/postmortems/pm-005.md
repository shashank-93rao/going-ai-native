# Postmortem: inventory degradation (INC-2235)

**Author:** on-call, core team

## Summary

A security group change removed the rule allowing traffic from inventory to kafka-ingest on port 5432. Customers saw elevated errors on inventory, ledger, search.

## Timeline (UTC)

- 09:10 First alert fired: error ratio above SLO on inventory.
- 09:13 Incident declared SEV3; incident commander assigned.
- 09:22 Upgraded to SEV2 after impact spread to search.
- 12:16 Mitigation applied.
- 12:30 Error rates back to baseline; incident resolved.

Later log analysis showed impact actually began at 09:05, before any alert.

Customer-visible impact lasted from 09:05 until resolution at 12:30.

## Root cause

A security group change removed the rule allowing traffic from inventory to kafka-ingest on port 5432. Connections hung until TCP timeout rather than failing fast.

## Impact

Customers saw elevated errors on inventory, ledger, search. Affected services: inventory, ledger, search.

## Action items

- [ ] Manage security groups through reviewed IaC only
- [ ] Add a synthetic probe for this path
