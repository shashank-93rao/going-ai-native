# Postmortem: auth degradation (INC-2256)

**Severity:** SEV2 | **Duration:** 4h 11m | **Author:** on-call, payments team

## Summary

A security group change removed the rule allowing traffic from auth to inventory on port 5432. Customers saw elevated errors on auth, search.

We initially suspected inventory because its dashboards were noisy, but its error rate and latency were within normal bounds throughout and it was not affected.

## Timeline (UTC)

- 13:37 Impact begins: error ratio on auth starts rising.
- 14:04 First alert fired: error ratio above SLO on auth.
- 14:07 Incident declared SEV2; incident commander assigned.
- 17:37 Mitigation applied.
- 17:48 Error rates back to baseline; incident resolved.

## Root cause

A security group change removed the rule allowing traffic from auth to inventory on port 5432. Connections hung until TCP timeout rather than failing fast.

## Impact

Customers saw elevated errors on auth, search. Affected services: auth, search.
