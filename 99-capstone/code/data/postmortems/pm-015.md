# Postmortem: kafka-ingest degradation (INC-2558)

**Severity:** SEV2 | **Duration:** 1h 24m | **Author:** on-call, core team

## Summary

Our upstream card-network provider returned intermittent 503s. Customers saw elevated errors on kafka-ingest, notifications.

## Timeline (UTC)

- 17:34 Impact begins: error ratio on kafka-ingest starts rising.
- 17:44 First alert fired: error ratio above SLO on kafka-ingest.
- 17:47 Incident declared SEV2; incident commander assigned.
- 18:51 Mitigation applied.
- 18:58 Error rates back to baseline; incident resolved.

## Root cause

Our upstream card-network provider returned intermittent 503s. kafka-ingest had no circuit breaker on that call path, so request threads blocked on the provider until pools were exhausted.

## Impact

Customers saw elevated errors on kafka-ingest, notifications. Affected services: kafka-ingest, notifications.

## Action items

- [ ] Add a circuit breaker on the provider call path
- [ ] Bulkhead provider calls into their own pool
