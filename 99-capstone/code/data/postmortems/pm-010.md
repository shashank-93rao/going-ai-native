# Postmortem: checkout degradation (INC-2102)

**Severity:** SEV2 | **Duration:** 3h 7m | **Author:** on-call, payments team

## Summary

A schema migration on checkout backfilled NULL into a column the read path assumed was non-null. Customers saw elevated errors on checkout.

## Timeline (UTC)

- 11:32 First alert fired: error ratio above SLO on checkout.
- 11:35 Incident declared SEV2; incident commander assigned.
- 13:43 Mitigation applied.
- 14:13 Error rates back to baseline; incident resolved.

Later log analysis showed impact actually began at 11:06, before any alert.

## Root cause

A schema migration on checkout backfilled NULL into a column the read path assumed was non-null. Rows written during the backfill window failed deserialization.

## Impact

Customers saw elevated errors on checkout.

## Action items

- [ ] Make the backfill write a sentinel instead of NULL
- [ ] Add a contract test for nullable columns
