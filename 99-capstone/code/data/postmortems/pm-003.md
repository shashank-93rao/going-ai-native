# Postmortem: ledger degradation (INC-2362)

**Severity:** SEV3 | **Duration:** 2h 52m | **Author:** on-call, platform team

## Summary

Our upstream card-network provider returned intermittent 503s. Customers saw elevated errors on ledger, payments.

## Timeline (UTC)

- 09:36 Impact begins: error ratio on ledger starts rising.
- 10:07 First alert fired: error ratio above SLO on ledger.
- 10:10 Incident declared SEV3; incident commander assigned.
- 12:01 Mitigation applied.
- 12:28 Error rates back to baseline; incident resolved.

## Root cause

Our upstream card-network provider returned intermittent 503s. ledger had no circuit breaker on that call path, so request threads blocked on the provider until pools were exhausted.

## Impact

Customers saw elevated errors on ledger, payments. Affected services: ledger, payments.

## Action items

- [ ] Add a circuit breaker on the provider call path
- [ ] Bulkhead provider calls into their own pool
