# Postmortem: inventory degradation (INC-2454)

**Duration:** 1h 26m | **Author:** on-call, core team

## Summary

A schema migration on inventory backfilled NULL into a column the read path assumed was non-null. No customer-facing impact; internal batch jobs and dashboards were delayed.

## Timeline (UTC)

- 09:56 Impact begins: error ratio on inventory starts rising.
- 10:23 First alert fired: error ratio above SLO on inventory.
- 10:26 Incident declared SEV3; incident commander assigned.
- 10:35 Upgraded to SEV2 after impact spread to inventory.
- 10:54 Mitigation applied.
- 11:22 Error rates back to baseline; incident resolved.

## Root cause

A schema migration on inventory backfilled NULL into a column the read path assumed was non-null. Rows written during the backfill window failed deserialization.

## Impact

No customer-facing impact; internal batch jobs and dashboards were delayed.

## Action items

- [ ] Make the backfill write a sentinel instead of NULL
- [ ] Add a contract test for nullable columns
