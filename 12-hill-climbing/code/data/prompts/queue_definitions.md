## Queue definitions
- payments: payments-api, checkout-svc, card authorization, payment feature flags.
- platform: Kubernetes nodes and node pools, autoscaling, pod scheduling and eviction, NTP and host config.
- data-pipeline: Kafka brokers and consumers, CDC connectors, Airflow DAGs, the warehouse.
- database: Postgres primaries and replicas, connection limits, vacuum, indexes, buffer cache.
- identity: auth-svc, SSO/SAML, token signing keys, JWKS.
- edge: CDN POPs, load balancers, TLS termination, cache purges.
Route to the team that owns the SATURATED OR BROKEN RESOURCE, not the team whose service shows the symptom.
A pool exhausted against a database is database. Pods OOMKilled or evicted for node pressure is platform.
